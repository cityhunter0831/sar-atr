## Exp A — 클러터 전이 (Clutter Transfer, 논문 Table 4)

### 논문이 사용한 방법

**문제**: SAR 이미지 = 표적(전차) + 클러터(배경). CNN이 배경 패턴을 외우면("이 풀밭 = BMP2") 배경이 달라질 때 성능이 급락한다(**배경 편향**).

**해법 — 클러터 전이**: SAR-Bake 픽셀 주석으로 표적/그림자/배경을 분리 → 표적을 다른 배경에 feather blending으로 합성 → 모델이 배경이 아닌 **표적 자체**에 집중하게 학습.

**4가지 통제 조건으로 "배경이 바뀌면 붕괴하고, 전이하면 회복되는가"를 체계적으로 검증**:

| 조건 | 학습 | 테스트 | 검증하는 것 |
|---|---|---|---|
| ① MSTAROR | 원본 | 원본 | 기준선 |
| ② TrainOR+TestCT | 원본 | 전이 배경 | 도메인 갭 (얼마나 떨어지는가?) |
| ③ TrainCT+TestCT | 전이 | 전이 | 전이 학습으로 회복 가능한가? |
| ④ TrainCTx2+TestCT | 2배 전이 | 전이 | 더 다양한 배경이 도움 되는가? |

논문 결과(SMPL7): ① 98.1% → ② 38.6%(**급락**) → ④ 96.0%(**회복**).

### 우리 재현 방법
- **데이터셋**: gengzhe2015 공개 데이터 (논문 저자 직접 업로드), 5클래스(2S1, BMP2, BTR70, T72, ZSU23)
- **모델**: SMPL + ResNet18, 각 3 seed 평균
- **코드**: `load_condition()`으로 조건별 로드, 4조건 × 2모델 × 3seed = 24회 학습
- **트러블슈팅**: CTx2 폴더에서 btr70·t72·zsu23 누락 → 원본 zip 재압축 해제(3563장, 5클래스 완전)로 해결

### 개선 #1 — SSIM 기반 전이 품질 정량화

**왜 필요한가**: 논문은 "전이하면 96%로 회복"이라고만 보고한다. 그러나 전이 이미지의 표적-배경 **경계가 부자연스러우면**(짜깁기 아티팩트) 모델이 경계선을 표적 특징으로 오인해 "잘못된 이유로 맞추는" 위험이 있다. **품질 근거가 없다**.

**방법**: 표적-배경 경계 주변 패치의 SSIM(구조적 유사도, 밝기·대비·구조 3축, 0~1)을 원본 대비 측정.

**결과**: **SSIM = 0.9472 ± 0.0024** → 경계 아티팩트 극히 낮고, 표적 구조가 충실히 보존됨. 참고로 JPEG(quality=50)의 SSIM이 약 0.92~0.95이므로, 클러터 전이는 JPEG 압축 정도의 열화만 일으킨다.

**의미**: 96% 회복이 경계 아티팩트 오인이 아니라 **표적 자체의 특징 학습**에 의한 것임을 품질로 보증. 표준편차 0.0024(매우 작음) = 어느 이미지든 경계 품질이 균일하게 높다.

### 결과 해석 — 그래프 `exp_a_clutter_transfer.png`

막대그래프의 x축은 4가지 조건, y축은 정확도(%). 파란 막대가 우리, 점선이 논문.

**읽는 법**: ①→② 하락폭 = "배경 편향이 얼마나 심각한가". ②→④ 회복폭 = "클러터 전이가 얼마나 효과적인가". 우리는 ④에서 논문(96.0%)을 **2.8%p 초과**(98.8%).

### 결론 및 논문 대비 비교

| 조건 | 우리 SMPL | 논문 SMPL7 | 우리 RN18 | 논문 RN18 |
|---|---|---|---|---|
| MSTAROR | 96.0±2.6% | 98.1±0.72% | 100.0±0.0% | 99.8±0.06% |
| TrainOR+TestCT | **67.7±0.6%** | 38.6±1.17% | **81.9±1.6%** | 55.2±1.42% |
| TrainCT+TestCT | **96.3±0.6%** | 91.5±0.93% | **99.7±0.4%** | 97.5±0.65% |
| TrainCTx2+TestCT | **98.8±0.3%** | 96.0±1.03% | **99.9±0.1%** | 98.4±0.35% |

- **완전 재현**: "급락→회복→추가향상" 서사 패턴 완벽 재현. CTx2에서 논문 초과 달성.
- **② 우리 67.7% vs 논문 38.6%**: 공개 데이터의 전이 배경 다양성·난이도 차이. 서사 패턴은 동일.
- **SSIM 0.9472**: 전이 품질이 높아 회복 효과가 신뢰할 수 있음을 정량 입증 (개선 #1).

## Exp B — 위상이력(PH) 보간 증강 (논문 Table 2·3)

### 논문이 사용한 방법

**문제**: 실측 SAR 데이터가 클래스당 24~32장(총 136장)뿐인 **few-shot** 상황 → baseline 56.6%에 머무름.

**왜 단순 증강이 안 되는가**: SAR는 전자기파 반사를 기록하므로, 방위각이 1°만 달라져도 산란 패턴이 변한다. 단순 기하 변환(회전/플립)은 물리적으로 존재하지 않는 패턴을 만들어 오히려 해를 끼친다.

**논문 해법 — 위상이력(PH) 도메인 물리적 증강** (Agarwal et al. 2020):

SAR 표적의 핵심 물리: 금속 모서리, 포탑 꼭짓점 등 **소수의 산란점(scattering centers)**에 반사 에너지 집중(스파시티). 이 산란점의 위치와 반사 계수를 복원하면, **관측하지 않은 방위각의 이미지를 물리법칙에 따라 재합성** 가능.

**3단계 파이프라인**:

| 단계 | 하는 일 | 수학 |
|---|---|---|
| 1. PH 추출 | 이미지 → 2D FFT → 역Taylor → 극좌표 K-space | 이미지를 SAR 원시 주파수 도메인으로 변환 |
| 2. 희소 복원 | 그룹 Lasso(L2,1)로 산란점 계수 C 추정 (Eq.7) | 격자 10000점 중 ~5~10개 산란점만 활성화 |
| 3. 재합성 | 복원된 C로 ±6° 외삽 → IFFT (Eq.8) | 1장 → 196장 (136장 → 1088장+) |

### 우리 재현 방법 (하이브리드 파이프라인)

- **데이터**: MSTAR 5클래스, train El17°/test El15°, few-shot 136장(24/32/24/24/32), 64×64 crop, AT(ε=2)
- **증강**: 로컬 MATLAB(원본 Agarwal 코드) → `.mat` → Google Drive → Colab Python 학습
- **왜 MATLAB**: 논문이 "we adopt the method proposed in Agarwal et al."로 명시한 원본 구현체를 **있는 그대로** 실행이 가장 정확
- **σ_G=1.0 고정**: 2S1 대표이미지에서 σ_G=1 vs σ_G=2 잔차 차이 **0.002%** 정량검증 → 라인서치 제거

**❌ 기존 구현의 오류**: `interpolate_phase_history()` = 두 이미지의 PH **선형 평균**. 산란점을 전혀 안 씀 → 논문 방법 아님. Agarwal Fig.4b가 "선형보간은 산란점을 왜곡"시킨다고 직접 실증. 우리 1차 구현이 이 오류를 그대로 재현해 65% 정체.

### 엔지니어링 성과

| 성과 | 효과 |
|---|---|
| 100× 솔버 가속 (pagemtimes, 익명함수 제거) | 칩당 26분 → 18초 |
| 인덱싱 버그 수정 (상관 0.18 → 0.997) | 재생성 이미지 정상화 |
| 로그진폭(dB) 전처리 도입 | few-shot 정확도 72.1% → 88.5% |
| 툴박스 의존성 제거 (pdist2, imrotate) | 라이선스 없이 실행 가능 |

### 결과 해석 — 그래프 `exp_b_confusion_matrix.png`

**혼동행렬 2개 나란히 배치**. 행 = 실제 클래스, 열 = 예측 클래스, 대각선 = 정답.

**왼쪽 (Baseline, 55.9%)**: 대각선이 흐리고, T72↔BMP2, 2S1↔T72 사이 심한 혼동. 이 세 클래스는 모두 **tracked vehicle(궤도차량)**이라 산란 패턴이 유사. 136장으로는 미세한 차이를 구분 불가.

**오른쪽 (Aug, 88.5%)**: 대각선이 뚜렷해지고 tracked vehicle 혼동 크게 감소. BTR70(바퀴차)·ZSU23(자주대공포)는 거의 100%. 물리적 증강이 **다양한 방위각의 산란 패턴**을 제공하여 유사 클래스 구분 능력을 개선.

### 결론 및 논문 대비 비교

| 조건 | 선형보간(구버전) | 산란점 완전판(하이브리드) | 논문 SMPL/AT |
|---|---|---|---|
| Baseline (few-shot 136장) | 49.8% | **55.9%** (log-amp 60dB) | 56.6% |
| Aug (PH 증강) | 64.9% | **88.5%** (log-amp 60dB, AT) | **96.4%** |

**이 결과가 의미하는 것**:
1. **Baseline 55.9% ≈ 논문 56.6%**: few-shot 난이도를 정확히 재현. 데이터 구성(5클래스, 136장, cross-depression)이 정확함을 확인.
2. **증강 효과 +32.6%p**: 물리 기반 증강이 **물리적으로 의미 있는 새로운 관측**을 제공했다는 증거.
3. **잔여 갭 7.9%p**: tracked vehicle(T72 85.1%, 2S1 84.3%) 병목. σ_G 클래스별 미세조정으로 개선 여지.

**세부 트러블슈팅**:
- 인덱싱 버그: `generate_aug_images.m`에서 few-shot 압축순서와 전체 PH 인덱스 불일치 → 원본↔증강 상관 0.18 → 수정 후 0.997
- 로그진폭 전처리: SAR 진폭의 큰 dynamic range → CNN이 피크 2~3픽셀만 학습 → dB 압축(60dB)으로 72.1% → 88.5% (+16.4%p)
- AT vs LSM: AT **88.5%** vs LSM 87.1%. 합성 데이터에서는 AT의 판별 경계 날카롭게 유지 효과가 우위.

## Exp B 개선 #3 — XAI로 물리적 산란점 검증

### 왜 이 분석이 필요한가

모델이 88.5%를 달성했지만, **"왜" 맞추는가?** 산란점(물리적 근거)을 보고 분류하면 신뢰할 수 있는 모델이고, 노이즈나 비물리적 단서를 보면 우연히 맞추는 모델(실전에서 위험)이다. 논문은 이 질문을 다루지 않았다.

### 실험 설계

4가지 XAI 기법의 어트리뷰션 맵과 **물리적 산란점 마스크**(희소복원으로 식별된 ~5개 점)의 IoU를 측정:

| 방법 | 원리 | 해상도 | 특성 |
|---|---|---|---|
| Grad-CAM 8×8 | 마지막 conv 기울기 가중 | 8×8 | 빠르지만 거침 |
| Grad-CAM 16×16 | 한 단계 앞 conv (from_last=1) | 16×16 | 해상도 개선 |
| Occlusion | 일부 가리고 출력 변화 | 64×64 | **인과적** ("가리면 틀린다") |
| SmoothGrad-IG | 적분 기울기 + 노이즈 | 64×64 | **공리적** (수학적 완전 귀속) |

### 결과 해석 — 그래프 `exp_b_xai_iou.png`

x축 = 4가지 XAI 방법(해상도 순), y축 = IoU.

| 방법 | IoU | 해석 |
|---|---|---|
| Grad-CAM 8×8 | 0.12 | 8×8로는 점 산란체 국소화 불가 (구조적 천장) |
| Grad-CAM 16×16 | 0.19 | 해상도 올리면 개선 → 천장 확인 |
| Occlusion | 0.24 | 픽셀 단위로 인과적 기여 입증 |
| **SmoothGrad-IG** | **0.29** | 최고 정합, 랜덤(0.05) 대비 5.8배 |

**핵심: IoU가 0.12 → 0.19 → 0.24 → 0.29로 해상도↑에 따라 단조 증가.**

**의미**:
1. CAM 해상도의 구조적 천장을 데이터로 입증 (8×8 → 16×16으로 개선)
2. 픽셀 XAI(Occlusion, SmoothGrad-IG)가 천장을 극복
3. IoU 0.29는 이론 상한(~0.3~0.4) 근접 → **모델이 물리적 산란점을 분류 근거로 사용하는 강한 증거**
4. Occlusion의 인과적 보완: "여기를 빼면 틀린다" → 통계적 상관이 아닌 **인과적 기여** 직접 입증

## Exp C — 대비 증강 (Contrast Augmentation, 논문 Section 3 / Table 6)

### 논문이 사용한 방법

**문제**: SAMPLE의 synth 이미지는 시뮬레이션이라 real보다 배경 클러터가 약하고 대비가 다르다. synth 학습 → real 테스트 시 **도메인 갭**으로 성능 저하.

**논문 해법**: `ColorJitter(contrast=0.5)` → 대비를 [0.5, 1.5] 범위에서 무작위 변형, 이미지당 3배 증강. 학습 시에만 적용, 평가는 real 원본. 결과: RN18 91.9% → **94.5%** (+2.6%p).

**논문의 한계**: `contrast=0.5`·3레벨은 **근거 없이 임의 고정(매직넘버)**. 왜 0.5인지, 왜 3배인지 정당화 없음.

### 우리 재현+개선 방법 (2단 구조)

**1단계 — 논문 재현**: `ColorJitter(contrast=0.5)` ×3 그대로 적용 (baseline).

**2단계 — 개선 #2**: strength(0.1~0.9) × levels(1~4)를 **Optuna 베이지안 최적화** 20 trials로 자동 탐색. 각 trial 10 epoch 빠른 학습, 최적 조합 발견 후 60 epoch 풀 학습.

**누수 방지**: real을 val(20%)/test(80%) 분할. Optuna는 val만 사용, 최종 수치는 못 본 test(1076장)로 보고.

### 결과 해석 — 그래프 `exp_c_contrast_optuna.png`

**왼쪽 막대그래프**: ① no-aug(81.5%, 파란) → ② 논문(61.8%, 빨간, **-19.7%p**) → ③ Optuna(75.4%, 초록, **+13.6%p**). 점선은 논문 참조값(Ori 91.9%, Aug 94.5%).

**오른쪽 파라미터 테이블**: 논문 strength=0.500/levels=3 vs Optuna strength=0.317/levels=4.

**핵심 읽는 법**: ①→② 빨간 화살표가 "논문 매직넘버가 독이 됨"을, ②→③ 초록 화살표가 "Optuna가 회복시킴"을 보여준다.

### 결론 및 논문 대비 비교

| 조건 | 우리 결과 | 해석 |
|---|---|---|
| ① 증강 없음 (synth→real) | **81.5%** | synth→real 도메인 갭 기준선 |
| ② 논문 ColorJitter(0.5)×3 | **61.8%** (-19.7%p) | 과도한 대비 변형이 표적 구조 파괴 |
| ③ Optuna (strength=0.317, levels=4) | **75.4%** (+13.6%p) | 적절한 강도로 도메인 갭 감소 |

**이 결과가 의미하는 것**:

1. **매직넘버의 위험성**: 논문의 contrast=0.5가 **-19.7%p 역효과**. 대비를 [0.5, 1.5]로 크게 흔들면 SAR 표적의 미세한 산란점 간 상대 밝기가 파괴되어 오히려 분류가 어려워짐.

2. **Optuna 최적값의 물리적 해석**: strength=0.317(논문 0.500보다 보수적) → 변형 범위 [0.683, 1.317]. 표적 구조를 유지하면서 synth-real 갭만 좁히는 **"적정 강도"를 데이터가 스스로 선택**. levels=4(3→4)는 더 세밀한 변형 다양성 제공.

3. **방법론적 기여**: 근거 없는 매직넘버 → 데이터 기반 자동탐색으로 전환하면 (a) 역효과 방지 (b) 재현성 확보 (c) "왜 이 값인가" 정당화 가능. 이는 SAR-ATR뿐 아니라 **모든 증강 기법에 일반적으로 유효한 교훈**.

**절대 수치 갭(81.5 vs 논문 91.9)**: SAMPLE 로드 장수(1345장) vs 논문 Table 5(806장) 차이. 개선 서사(+13.6%p)와 무관.

## Exp D — OOD 탐지 (ODIN vs Mahalanobis, 논문 Figure 9)

### 논문이 사용한 방법

**문제**: 실전에는 학습에 없던 미지 표적(OOD)이 등장한다. 모델이 미지 표적을 기존 클래스로 자신 있게 오분류하면 치명적. **"모르는 것을 모른다고 말할 수 있는가?"**

**두 시나리오**:

| 유형 | 정의 | 예시 | 탐지 난이도 |
|---|---|---|---|
| **Near-OOD** | 학습 도메인(군사 차량) 내 미지 클래스 | SAMPLE holdout (J=1~3) | 어려움 |
| **Far-OOD** | 완전히 다른 도메인 | 선박(SAR-ship) | 쉬움 |

**두 방법 비교**:

| 방법 | 원리 | 강점 |
|---|---|---|
| **ODIN** | softmax 신뢰도 + temperature(T=1000) + 입력 섭동(ε=0.0014) | 구현 간단, 사전 학습 불필요 |
| **Mahalanobis** | 클래스별 특징 분포(평균/공분산) 거리 측정 | 특징 공간 구조 활용, 안정적 |

**평가 지표**: AUROC (0.5=랜덤, 1.0=완벽), TNR@95TPR (ID 95% 통과 시 OOD 차단율).

### 우리 재현 방법

- **ID**: SAMPLE 10클래스 (논문 Figure 9 기준으로 정정)
- **MiniSAR 대체**: 비공개 → 공개 SAR-ship (선박과 전차는 완전히 다른 SAR 반사 패턴 → far-OOD에 적합)
- **J=1,2,3**: holdout 클래스 수를 변화시켜 탐지 난이도 분석

### 결과 해석 — 그래프 `exp_d_ood.png`

**AUROC 히트맵**: 진한 색(높은 AUROC) = 탐지 잘 됨, 연한 색 = 탐지 안 됨. SAR-ship 행은 전 J에서 진한 색(1.000), holdout 행은 연한 색(~0.4~0.5).

**핵심 패턴**: far-OOD(SAR-ship)와 near-OOD(holdout)의 극단적 대비가 OOD 탐지의 도메인 거리 의존성을 시각적으로 보여준다.

### 결론 및 논문 대비 비교

| OOD 종류 | ODIN AUROC | Maha AUROC | 해석 |
|---|---|---|---|
| **Far-OOD (SAR-ship)** | 1.000 (J=1) | **1.000** (전 J) | 완벽 탐지 |
| **Near-OOD (holdout J=1/2/3)** | ~0.50 | 0.356/0.422/0.456 | 랜덤 수준 (탐지 불가) |

**이 결과가 의미하는 것**:

1. **도메인 거리 의존성**: SAR-ship(선박)은 전차와 반사 패턴이 완전히 다르다 → 특징 공간에서 거리가 크다 → Mahalanobis가 즉시 탐지(1.000). 반면 같은 군사 차량 도메인 내 미지 클래스는 특징이 겹쳐 탐지 불가(~0.45).

2. **Mahalanobis의 일관적 우위**: ODIN은 J=2에서 AUROC=0.000(점수 역전 이상치) 발생 → 불안정. Mahalanobis는 전 J에서 1.000으로 완벽·안정 → **cross-domain 탐지에 적합**. 이유: 특징 공간 전체 구조(공분산)를 활용하므로 도메인 갭이 클수록 탐지력 강해짐.

3. **Near-OOD 한계의 본질**: 동일 군사 차량 도메인에서 "학습한 전차 vs 안 학습한 전차"를 구분하는 것은 **특징 표현 자체의 한계**. 단일 탐지 방법의 문제가 아니라 학습 표현의 구조적 한계.

4. **논문 패턴 완전 재현**: "far-OOD는 쉬움, near-OOD는 어려움" 정성적 결론 일치. ATR 시스템 설계 시 **"어떤 유형의 미지 위협까지 탐지할 것인가"를 사전 정의해야 함**을 시사.

## 전체 결론

### 재현을 통해 확인한 것

1. **물리 기반 증강은 범용 증강보다 우월하다**: 클러터 전이, 위상이력 보간, 대비 보정 모두 SAR 물리를 이해하고 활용하는 증강이며, 이 점이 높은 성능의 핵심.
2. **데이터 부족은 '물리로 만들기'로 해결 가능**: Exp B에서 136장 → 1088장+ 물리 증강으로 55.9% → 88.5% 달성. 추가 촬영 없이 기존 데이터의 물리 정보를 재활용.
3. **OOD 탐지는 도메인 거리에 의존**: far-OOD 완벽(1.0), near-OOD 불가(~0.45). ATR 설계 시 위협 유형 사전 정의 필요.

### 개선을 통해 기여한 것

1. **SSIM**: 성능 회복의 신뢰성 근거 제시 (경계 품질 0.9472)
2. **Optuna**: 매직넘버 -19.7%p 역효과 발견 → 자동탐색으로 +13.6%p 회복. 모든 증강 기법에 유효한 교훈.
3. **XAI**: 물리 기반 모델이 실제 산란점을 보고 분류함을 IoU 0.29로 입증. 군사 ATR의 설명가능성 요구에 기여.
